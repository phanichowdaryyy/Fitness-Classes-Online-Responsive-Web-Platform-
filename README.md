# 🏋️ Fitness Streaming Classes Website

## 📌 About the Project

The **Fitness Streaming Classes Website** is a modern web application designed to provide users with access to online fitness training sessions. It includes multiple pages for users, admin panel, class details, gallery, and contact features. The platform aims to deliver a clean and user-friendly experience for fitness enthusiasts.

---

## 🚀 Features

- 🔐 User Login System
- 👤 Separate User & Admin Pages
- 🏠 Home Page with Attractive UI
- 🏋️ Fitness Classes Section
- 🖼️ Gallery for Workout Images
- 📞 Contact Page for Queries
- 🎨 Responsive and Clean Design
- ⚡ Fast and Lightweight Frontend
